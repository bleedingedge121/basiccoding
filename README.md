# Java + GitHub Collaborative Learning Roadmap

## Goal

Two complete beginners learn:
- programming fundamentals,
- Java,
- Git/GitHub collaboration,
- debugging,
- project building,
- and teamwork.
---

# Rules for Fast Learning

## Rule 1

Never copy code without typing it.

---

## Rule 2

Break programs intentionally.
Learning debugging is critical.

---

## Rule 3

Write comments explaining logic.

Example:

```java
// outer loop controls rows
for(int i = 0; i < 5; i++) {

}
```

---

## Rule 4

Review each other’s code.
Reading code improves skill very fast.

---

## Rule 5
Do not jump into frameworks early.

Avoid:
- Spring Boot,
- Android,
- advanced backend frameworks.

First master:
- logic,
- OOP,
- debugging,
- Git.

---

# Rule 6

Consistency matters more than speed.

Even:

```text
1 hour daily for 6 months
```

is enough to become comfortable with Java fundamentals.
